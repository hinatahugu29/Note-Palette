NotePalette 使い方マニュアル

複数のノートを見渡せて、自動で残るメモアプリ

目次はじめにノートとページ配置と表示ファイル・画像検索保存と復旧ショートカット別PCへの移動

はじめに

NotePalette.exe を起動すればすぐ使えます。入力内容、配置、開いているページは自動保存されるため、通常の利用で保存操作は不要です。

上部右端の保存表示が「保存済み」になれば保存完了です。「保存エラー・再試行」と表示された場合は、そこをクリックしてください。

ノートとページ

ノートを作る

  • 上部の「＋ 新規」を押す
  • ボードの空いている場所をダブルクリックする
  • Ctrl＋Nを押す

ノートを操作する

  • ヘッダーをドラッグ：移動
  • 四隅のいずれかをドラッグ：大きさの変更（固定したい角を選べます）
  • ヘッダーをダブルクリック：最大化／元に戻す
  • タイトルをダブルクリック：タイトル変更
  • 「⋯」：名前変更、色変更、書き出し、複製、ウィンドウに出す、収納、最大化、削除
  • 📌：誤って閉じないよう保護
  • ⧉：現在の本文をクリップボードへコピー

ページを使う

  • ページ列の「＋」またはCtrl＋T：新しいページ（独立ウィンドウも共通）
  • ページ見出し（タブ）をドラッグ＆ドロップ：ページの並び替え
  • ページ列上でマウスホイール：タブバーの横スクロール
  • ページ名をダブルクリック：名前変更
  • Ctrl＋Tab／Ctrl＋Shift＋Tab：次／前のページへ移動（端では反対側へ循環）
  • Ctrl＋W：現在のページを閉じる。最後の1ページならノートを閉じる（独立ウィンドウでは確認付きでボードへ復帰）
  • ノート右下（独立ウィンドウは下部フッター）：本文の文字数・行数を表示（範囲選択中は選択文字数を表示）
  • 本文中のTab：字下げ
青い枠のノートが、ショートカット操作の対象です。📌をオンにすると、Ctrl＋Wでは閉じなくなります。

デスクトップへ出す

ノートの「⋯」から「ウィンドウに出す」を選ぶと、ノートを独立したウィンドウとしてボードの外へ出せます。独立ウィンドウでもページのドラッグ並び替えやホイールスクロール、ショートカット（Ctrl＋T、Ctrl＋W、Ctrl＋Tab、Ctrl＋S、Ctrl＋0）、下部ステータスバーでの文字数カウントに対応しています。独立ウィンドウの📌は常に手前へ表示する設定です。↙を押すかウィンドウを閉じると、メインボードへ戻ります。アプリ終了時に外へ出ていたノートは、次回起動時も独立ウィンドウで復元されます。

配置・表示・文字サイズ

  • 「自由配置／タイル表示」：好きな配置と自動整列を切り替えます。自由配置の位置は保持されます。
  • 各ノートの A−／A＋：そのノートだけ文字サイズを変更。Shiftを押しながらなら2pxずつ変更します。
  • 右上の「表示 ○%」：画面全体の倍率変更と、すべてのノートの文字サイズ統一。
  • Ctrl＋マウスホイール：画面全体の倍率を素早く変更。
  • Ctrl＋0：表示倍率を100%に戻す（独立ウィンドウでは文字サイズを14pxにリセット）。

外部ファイルと画像

テキストファイル

txt、md、html、css、js、json、csv、logなどを画面へドロップすると、内容を新しいノートとして取り込みます。複数ファイルなら、1つのノート内の複数ページになります。元ファイルとは連動しないコピーです。

HTMLやスクリプトは実行せず、文字として表示します。5MB超では確認が入り、50MB超では動作保護のため先頭5MBだけを取り込みます。

画像

画像ファイルをドロップするか、画像をコピーしてCtrl＋Vで貼り付けます。画像も移動・拡大縮小・最大化・削除できます。

外部へ書き出す

Ctrl＋Sで現在のページをUTF-8のテキストファイルとして保存できます（独立ウィンドウも共通）。これは任意の場所へ渡すためのコピーで、以後の編集とは連動しません。

全文検索

Ctrl＋Fで検索欄へ移動します。ノートタイトル、ページ名、本文が検索対象です。結果一覧をクリックするか、Enterで該当ページへ移動し、一致箇所まで自動スクロールしてテキストを選択します。Escで検索を解除します。

保存・収納・復旧

  • ▣ 収納：削除せず、ボードから一時的に隠します。収納中の件数はボタンにバッジ表示され、押すと画面下に一覧がスライド表示されます。クリックでボードへ戻せます。Ctrl＋Shift＋Aでアクティブなノートを収納できます。一覧の📌を押すと、開いたまま固定（次回起動後も維持）できます。
  • 🗑 ゴミ箱：削除したノート、ページ、画像を後から復元できます。「すべて空にする」で完全消去も可能です。削除直後は画面下の「元に戻す」も利用できます。
  • ⚙ バックアップ履歴：起動時と約1時間ごとの状態へ戻せます。
  • ⚙ 全データをZIP保存：別の場所へ完全なバックアップを作ります。
  • ⚙ ZIPバックアップを読込：ZIP保存した状態を復元します。
  • ⚙ 全ノートをTXTで書き出す：一般的なファイルとしてまとめて取り出します。
  • ⚙ 保存場所を開く：実際のデータフォルダを表示します。
大切な内容は、ときどき「全データをZIP保存」で別ドライブにもコピーしておくと安心です。

別PCへの移動・配布

NotePalette-win32-x64フォルダを、丸ごとコピーしてください。アプリ本体と、その横に作られるNotePaletteDataにメモや設定が入っています。

  1. NotePaletteを終了する
  2. NotePalette-win32-x64フォルダ全体をUSBメモリなどへコピーする
  3. 別PCでフォルダ内のNotePalette.exeを起動する
NotePalette.exeだけを取り出すと起動できません。必ずフォルダごと移動してください。

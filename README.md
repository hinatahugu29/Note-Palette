# NotePalette

複数のノートをボード上で見渡せて、テキストエディタのように内容を失いにくい、Windows向けのローカルメモアプリです。

複数のノートを1枚のボードへ自由に並べ、それぞれのノートに複数のページを持たせられます。入力内容、ノートの位置や大きさ、表示状態は自動保存され、アカウント登録やクラウド接続を必要としません。

ノートはメインボード内だけでなく、独立したウィンドウとしてデスクトップへ出すこともできます。全体を見渡したいときはボード、作業中の内容を常に表示したいときは独立ウィンドウ、という使い分けができます。

## 主な特徴

### ノートを見渡せるボード

- ノートをドラッグして自由に配置し、右下からサイズを変更
- 画面端やほかの要素へ近づけると、8px以内で辺が吸着
- 自由配置と自動グリッドの「タイル表示」を切り替え可能
- タイル表示中も自由配置時の座標を保持し、ドラッグで順序を変更可能
- ノートの最大化、7色の色分け、前面化、複製に対応
- ノートを独立ウィンドウへ出し、デスクトップ上の付箋のように配置可能
- 独立ウィンドウの位置・大きさ・最前面表示を保存し、次回起動時にも復元
- 独立ウィンドウを閉じるか `↙` を押すと、同じノートをメインボードへ戻せる
- 使わないノートは削除せず「収納」し、後からボードへ復帰可能

### 1つのノートに複数のページ

- ノートごとに複数ページを追加
- ページ見出し（タブ）のドラッグ＆ドロップによる並び替え
- ページ数が多いときのタブバーのマウスホイール横スクロール
- ノートタイトルとページ名を個別に変更
- ページごとの本文とスクロール位置を保存
- ノート下部に本文の文字数・行数（テキスト選択時は選択文字数）を控えめに表示
- `Tab` キーをフォーカス移動ではなく字下げとして入力
- ノート単位の文字サイズ調整と、全ノートの文字サイズ一括変更
- ピン留めしたノートは、不意のページ削除やノート削除から保護

### デスクトップ付箋として使う

ノートの `⋯` メニューから「ウィンドウに出す」を選ぶと、そのノートがメインボードから独立ウィンドウへ移動します。同じノートを2か所で同時編集しない方式のため、本文やページ構成の保存が競合しません。

独立ウィンドウでは、次の操作ができます。

- ノート名とページ名の変更
- ページの追加・切り替え・削除（`Ctrl+T`、`Ctrl+Tab`、`Ctrl+W` 等のショートカット対応）
- ページのドラッグ＆ドロップ並び替え、タブバーのホイール横スクロール
- 本文の編集と自動保存、下部ステータスバーでの文字数・行数・選択文字数の表示
- 文字サイズの変更（`Ctrl+0` で標準の14pxへリセット）
- 現在のページをクリップボードへコピー、または `Ctrl+S` で外部TXT保存
- 📌による「常に手前に表示」
- `↙` またはウィンドウを閉じてメインボードへ戻す

アプリ自体を終了した場合はボードへ戻さず、独立状態を維持します。次回起動時に、保存された位置と大きさで再び独立ウィンドウを開きます。メインボード上の📌は削除防止、独立ウィンドウ上の📌は最前面表示を意味します。

### 検索とすばやい操作

- ノートタイトル、ページ名、本文を横断する全文検索
- 検索結果に本文の抜粋と `ノートタイトル › ページ名` を表示
- 結果をクリック、または `Enter` で該当ページへ移動し、一致箇所まで自動スクロール＆テキスト選択
- 表示倍率は50〜300%で変更可能
- よく使う操作はキーボードショートカットに対応

### テキストと画像の取り込み

- 一般的なテキストファイルをボードへドラッグ＆ドロップ
- 単一ファイルは1ノート、複数ファイルは1ノート内の複数ページとして取り込み
- UTF-8、UTF-8 BOM、UTF-16 LE/BE、Shift_JISを判定
- HTMLやコードも実行せず、プレーンテキストとして表示
- 5MB超のファイルには警告を表示し、50MB超は先頭5MBだけを安全にプレビュー
- 画像はファイルのドロップまたはクリップボードから貼り付け可能
- 画像も移動、リサイズ、最大化、コピー、タイル配置に対応

取り込んだファイルは元ファイルと同期せず、NotePalette内の独立したコピーとして保存されます。対応する主なテキスト形式は `txt`、`md`、`html`、`css`、`js`、`ts`、`json`、`xml`、`csv`、`log`、`yaml`、各種ソースコードなどです。画像は PNG、JPEG、GIF、WebP、BMPに対応します。

## データを守る仕組み

NotePaletteは、本文を独自データベースへ閉じ込めず、通常のUTF-8テキストファイルとして保存します。

- 入力後500msで自動保存
- 終了時に未保存の変更を書き出してから終了
- 一時ファイルへ書いてから置き換えるアトミック保存
- 同じファイルへの書き込みを直列化し、保存処理の競合を防止
- 独立ウィンドウの編集中は、メインボード側の保存が古い内容で上書きしないよう統合
- 起動時と起動中1時間ごとに、配置・全本文・画像を同じ時点のスナップショットとして保存
- バックアップは直近30世代を保持し、画面から任意の時点へ復元可能
- `board.json` が壊れた場合は破損ファイルを退避し、最新の配置バックアップから復旧
- 異常終了を検知し、次回起動時に自動保存データから復帰したことを通知
- 保存に失敗した場合は未保存状態を維持し、ステータスから再試行可能

ノート、ページ、画像を削除しても、実体はすぐに消去されず専用のゴミ箱へ移動します。削除直後は6秒間表示される「元に戻す」から、それ以降はツールバーのゴミ箱から復元できます。ゴミ箱内のアイテムは「すべて空にする」ボタンで一括して完全に消去することも可能です。

## バックアップと持ち出し

画面右上の歯車メニューから、次の操作ができます。

- 過去30世代のバックアップ履歴を表示・復元
- 配置、全本文、画像を1つのZIPへ保存
- ZIPバックアップを読み込み、アプリ全体を復元
- 全ノートを一般的なフォルダと `.txt` ファイルへ一括書き出し
- 実際のデータ保存場所をExplorerで開く

ZIPの読み込み前と履歴の復元前には、現在の状態も自動的に退避されます。ZIP読み込みでは、不正なパス、想定外の内容、2GBを超える展開データを拒否します。

## 主な操作

| 操作 | 方法 |
| --- | --- |
| 新しいノート | `Ctrl+N`、またはボードの空いている場所をダブルクリック |
| 新しいページ | `Ctrl+T`、またはノート内の `+`（独立ウィンドウも共通） |
| ページを切り替える | `Ctrl+Tab` / `Ctrl+Shift+Tab`（独立ウィンドウも共通） |
| ページまたはノートを閉じる | `Ctrl+W`（独立ウィンドウも共通、最後の1ページは確認付き） |
| ページの並び替え | ページ見出し（タブ）をドラッグ＆ドロップ（独立ウィンドウも共通） |
| タブバーの横スクロール | タブバー上でマウスホイール（独立ウィンドウも共通） |
| ノートを複製する | `Ctrl+D` |
| 現在のページをTXT保存 | `Ctrl+S`（独立ウィンドウも共通） |
| 全文検索 | `Ctrl+F`、検索中に `Enter` で次の結果へ移動・本文選択 |
| 表示倍率を変える | `Ctrl+ホイール` |
| 表示倍率を100%へ戻す | `Ctrl+0`（独立ウィンドウでは文字サイズを14pxへ戻す） |
| ノートを最大化する | ヘッダーをダブルクリック、または `⤢` |
| ノートを外へ出す | ノートの `⋯` から「ウィンドウに出す」 |
| ボードへ戻す | 独立ウィンドウ右上の `↙`、またはウィンドウを閉じる |
| 検索や最大化を解除する | `Esc` |
| ノートタイトルを変える | タイトルをダブルクリック |
| ページ名を変える | ページをダブルクリック |
| 常に手前へ表示する | 独立ウィンドウ右上の `📌` |
| 文字数・行数を確認する | 各ノート右下（独立ウィンドウは下部フッター）に表示。選択中は選択文字数を表示 |

`Ctrl+W` は、複数ページがある場合は現在のページを閉じ、最後の1ページの場合はノートごと閉じます。ピン留め中のノートには作用しません。

## 保存場所とデータ形式

配布版では、原則として実行ファイルと同じ場所にある `NotePaletteData` フォルダへ保存します。アプリの置かれた場所が書き込み禁止の場合は、Windowsのドキュメント内にある `NotePalette` フォルダを使用します。開発実行時もドキュメント側を使用します。

環境変数 `NOTEPALETTE_DATA` を設定すると、任意の保存先へ変更できます。

```text
NotePaletteData/
├─ board.json                 # ノート・画像の配置、独立状態、表示状態
├─ items/<ノートID>/<ページID>.txt # 各ページの本文
├─ images/                    # 取り込んだ画像
├─ backups/                   # 世代バックアップ
├─ trash/                     # 削除したデータ
└─ window.json                # ウィンドウ位置とサイズ
```

配布版を別のPCや別の場所へ移す場合は、`NotePalette-win32-x64` フォルダ全体をコピーしてください。

## 技術構成

- Electron 44
- TypeScript 7
- Node.js標準API
- HTML / CSS / DOM API
- `adm-zip`（バックアップZIPの作成・読み込み）

バンドラーやフロントエンドフレームワークは使わず、TypeScriptをそのままコンパイルする小さな構成です。ElectronのrendererではNode.js連携を無効化し、`contextIsolation` とsandboxを有効にしています。ファイル操作はpreloadで公開した限定APIを介してmainプロセスで行います。また、画面側には外部リソースやインラインスクリプトを許可しないContent Security Policyを設定しています。

主要なコードの役割は次のとおりです。

| 場所 | 役割 |
| --- | --- |
| `src/main/main.ts` | ウィンドウ、アプリのライフサイクル、OS機能、IPC |
| `src/main/storage.ts` | 自動保存、ゴミ箱、バックアップ、ZIP、全件書き出し |
| `src/main/preload.ts` | rendererへ公開する限定API |
| `src/renderer/app.ts` | ノート・ページ・画像・検索などのUIと状態管理 |
| `src/renderer/detached.ts` | 独立ウィンドウ内のページ編集と保存 |
| `src/renderer/lib/` | 配置計算、文字コード判定、DOM補助、文字数・行数計算 |
| `src/shared/types.ts` | ボードやノートなどの共有データ型 |
| `static/` | 画面のHTMLとCSS |

## 開発・実行

```powershell
npm install
npm start
```

そのほかのコマンドです。

```powershell
npm run build   # TypeScriptをコンパイル
npm test        # ビルド後に全自動テストを実行
npm run test:ui # Electron上のUI回帰テスト
npm run pack    # Windows x64向け配布フォルダを生成
```

`npm run pack` の出力先は `release/NotePalette-win32-x64/` です。同じ出力先で再ビルドした場合も、既存の `NotePaletteData` は一時退避してから戻すため、利用中のメモを保持します。

## テスト

自動テストでは、次の範囲を確認しています。

- 文字コード判定、ファイル種別判定、サイズ表示、文字数・行数および選択文字数カウント
- 配置のクランプ、辺への吸着、タイル計算
- 初回データ作成と本文の再読み込み
- 本文・画像を含むスナップショットと履歴復元
- ノート・ページ・画像のゴミ箱復元、およびゴミ箱のすべて空にする完全消去
- ZIPバックアップの書き出しと別保存先への読み戻し
- 全ノートのTXT書き出し
- 実際のElectron画面上での新規作成、入力、ページ、複製、文字サイズ、ピン、色、移動、リサイズ、タイル、検索、最大化、削除、復元
- ノートを独立ウィンドウへ移動し、ウィンドウ状態を次回起動用に保存
- 独立ウィンドウ側の編集内容を、メインボード側の保存で上書きしないこと

## 現在の方針と制約

- Windows x64向けのデスクトップアプリです。
- クラウド同期や共同編集はありません。
- リッチテキストではなく、長期的に扱いやすいプレーンテキストを優先しています。
- 画像貼り付けなど一部の実機操作は、利用環境による最終確認が必要です。
- ノートの最小サイズは180×110pxで、画面から完全にはみ出さないよう制限されます。
- 独立ウィンドウはWindowsの通常ウィンドウとして表示され、最小サイズは260×180pxです。
